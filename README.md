One haiku about debugging, 5-7-5, seventeen syllables. A program that writes it to /output/entry.txt — and checks the shape before it writes, so it can never emit a malformed entry.

> Cursor blinks at three,
> the breakpoint hits my own code,
> written by past me.

## Run it

```sh
python3 main.py
```
